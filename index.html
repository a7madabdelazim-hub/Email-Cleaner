Mail Cleaner

One-time setup (free, ~5 minutes)

Gmail only lets an app read your mail if you create a free "client ID" for it in your own Google account. You do this once.

  1. Open console.cloud.google.com → create a project named Mail Cleaner.
  2. APIs & Services → Library → search Gmail API → Enable.
  3. OAuth consent screen: User type External, app name Mail Cleaner, your email. Under Test users add every Gmail address you will use here.
  4. Credentials → Create credentials → OAuth client ID → type Web application.
