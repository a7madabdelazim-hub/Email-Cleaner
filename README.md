# Mail Cleaner

Groups your Gmail by sender so you can delete or block in bulk. Works on iPhone (Add to Home Screen) with several Gmail accounts.
يجمع بريد Gmail حسب المرسل، وتختار ما تحذفه أو تحظره. يعمل على الآيفون ويدعم أكثر من حساب.

## Try it first (no sign-in)
Open `index.html?demo` — fake data, nothing is deleted.

## Put it online (free, GitHub Pages)
1. New GitHub repo, e.g. `gmail-cleaner` → upload `index.html`, `icon.png`, `manifest.json`.
2. Repo → Settings → Pages → Branch: `main` / root → Save.
3. Open `https://a7madabdelazim-hub.github.io/gmail-cleaner/` in Safari.
4. Follow the one-time setup shown on screen (Google client ID). The exact redirect URI to register is shown there.
5. Safari → Share → Add to Home Screen.

Google sign-in does not work when opening the file directly from Files — it must be on a web address.
